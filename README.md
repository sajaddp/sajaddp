## Selected Open-Source Work

### [Iran Administrative Divisions Dataset](https://github.com/sajaddp/list-of-cities-in-Iran)

[![GitHub stars](https://img.shields.io/github/stars/sajaddp/list-of-cities-in-Iran?style=flat-square&label=Stars)](https://github.com/sajaddp/list-of-cities-in-Iran/stargazers)

A comprehensive open-source dataset of **Iran’s provinces, counties, districts, cities, and rural districts**, available in **CSV**, **JSON**, and **XLSX** formats. The repository includes practical integration guides for PHP, JavaScript, TypeScript, Go, Python, PostgreSQL, MySQL, MongoDB, and other ecosystems.
